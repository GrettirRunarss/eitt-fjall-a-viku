# Eitt fjall á viku

Settu `index.html` og `fjoll.json` í sama GitHub repository.

GitHub Pages:
Settings → Pages → Deploy from a branch → main → /(root)

Þegar þú færir fjöll:
1. Ýttu á „Vista staðsetningar“.
2. Ný `fjoll.json` skrá niðurhalast.
3. Farðu í GitHub repository-ið.
4. Skiptu gömlu `fjoll.json` út fyrir nýju.
5. Eftir að GitHub Pages uppfærist sjá öll tæki sömu staðsetningar.
